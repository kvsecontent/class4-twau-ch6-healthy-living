# Happy and Healthy Living – Sports Games (Class 4 TWAU, Chapter 6)

Interactive smartboard games for NCERT Class 4 *Our Wondrous World* Chapter 6 **Happy and Healthy Living** (topic: *Enjoy Sports*).

- **Games Wheel** – spin the wheel (Kho-kho, Kabaddi, Skipping, Cycling, Lagori, Cricket), name the game and choose the body part that moves the most. Two teams, one point per correct answer.
- **Indoor or Outdoor?** – drag 16 game cards into the Indoor Games or Outdoor Games box.
- **Simon Says** – 16 action cards (run, jump, stretch, bend, clap, tree pose …) with “Simon says” chance, read-aloud and timer.

Single self-contained `index.html` — no internet libraries needed.
